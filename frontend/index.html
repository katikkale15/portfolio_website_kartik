03 — Research

Publications

Peer-reviewed work in computer vision for transportation and machine learning for computational fluid dynamics.

Latest Computer Vision Open Access

Real-Time Traffic Flow Prediction with Drones and Adaptive Signal Control Using YOLO v8

S. Pavithra, R. Chandak, K. Kale, A. Choudhary, T. Sachan · Transportation Research Interdisciplinary Perspectives, Vol. 40, 102295 (Elsevier)

A real-time framework that combines drone footage, YOLOv8 vehicle detection and tracking, and ground-level data from the Google Maps API to estimate traffic density. A regression model forecasts optimal signal intervals from the live data, so signal timings adjust dynamically to reduce congestion. Runs on a Raspberry Pi 5 with a drone-mounted GPS module.
